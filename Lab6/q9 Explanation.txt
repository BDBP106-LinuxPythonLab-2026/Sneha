(i) Initial dirs -v -l 
Explanation: By default, the stack contains only the current directory. The -v option displays the stack vertically with index numbers, and the -l option forces long listing format, printing full absolute paths instead of the tilde (~) shorthand.

(ii) & (iii) Adding Entries and Stack Behavior
Explanation: The directory stack operates on a Last-In, First-Out (LIFO) data structure. Each pushd command changes the current working directory and pushes that new path onto the top of the stack. The most recently added directory (~/Documents) occupies index 0, pushing older entries down to higher index numbers.

(iv) Executing pushd +1
Explanation: This command rotates the stack cyclically. It shifts the entry at index 1 to the top of the stack (index 0) and automatically changes the current working directory to that path. No entries are added or removed.

(v) Executing cd -
Explanation: This toggles the current working directory back to the previous working directory. It only updates the value at index 0 (the current directory) and does not modify, shift, or rotate any other entries in the directory stack.

(vi) Executing cd /tmp 
Explanation: This directly changes the current working directory to /tmp. Standard cd commands only overwrite index 0 of the stack to reflect the new location, leaving the rest of the historical entries (index 1 and below) completely unchanged.

(vii) Executing popd
Explanation: This removes the topmost entry (index 0) from the stack. The remaining entries shift upward (the entry at index 1 becomes the new index 0), and the shell automatically changes the current working directory to this new top entry.

(viii) Executing popd +2 vs pushd +2
Explanation:popd +2: Deletes the specific entry at index 2 from the stack, causing subsequent entries to shift up. It does not change the current working directory.pushd +2: Does not delete anything; it rotates the stack to bring the entry at index 2 to the top (index 0), changing the current working directory to that path.

(ix) The Role of Index '0'
Explanation: Index 0 always represents the current working directory. Regardless of the navigation command used (cd, pushd, or popd), index 0 dynamically updates to track the user's active location in the file system, while index 1 and below hold the historical memory of the stack.
